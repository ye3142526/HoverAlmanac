# 悬停图鉴 (Hover Almanac) v1.1

把鼠标移到**植物**或**僵尸**身上，按住 **Shift**（可在设置里改成 Ctrl / Alt），就在旁边弹出这个对象的图鉴。

- **锁定**：图鉴一旦弹出，鼠标可以随便移到图鉴上，不会消失；**只有松开触发键才关闭**（对象死亡、窗口失焦也会关闭）。
- **可滚轮翻看**：图鉴内容是独立浮层，鼠标移上去滚轮即可上下翻，长简介、台词都能读完。
- **本地语言化**：自动跟随游戏当前语言（简体中文 / English），其他语言回退到中文；也可以在设置里手动指定。
- 支持全部植物与僵尸（含变体），显示名称、简介、阳光消耗 / 冷却 / 韧性 / 伤害 / 范围 / 家族、当前生命、所在行列、个性台词。

## 安装

1. 打开游戏，进入 **模组** 页面 → **导入**，选择本压缩包（`HoverAlmanac-1.1.0.zip`）。
2. 在模组列表里勾选 **悬停图鉴**，点 **保存**。
3. 点 **应用**。
4. 首次使用 JS 模组需要开启 **设置 → 实验性 → JS Modding**（会提示风险，确认一次即可），否则模组会被跳过。

> 游戏版本：0.16.15；GP-Next ≥ 1.5.5；`apiVersion: 2`。

## 使用

1. 进关卡后把鼠标移到植物 / 僵尸上。
2. 按住 **Shift**，图鉴弹出并锁定在这个对象上。
3. 鼠标移到图鉴上 → 滚轮翻看；鼠标移到别的对象上停约 0.4 秒 → 换成那个对象的图鉴。
4. 松开 **Shift** → 关闭。

## 设置（模组详情页）

| 设置 | 说明 |
| --- | --- |
| 启用悬停图鉴 | 总开关 |
| 触发按键 | Shift / Ctrl / Alt |
| 图鉴语言 | 跟随游戏语言 / 中文 / English |
| 显示个性台词 | 是否显示图鉴里的趣味台词 |
| 面板缩放 | 0.75 ~ 1.6 |
| 坐标投影方式 | 自动 / 相机投影 / 画布视图，定位不准时切换 |
| 投影水平/垂直偏移 | 像素微调，用于个别分辨率下的对位修正 |
| 显示调试信息 | 左下角显示命中、投影得分、数据来源、是否在卡片上等 |

模组详情页还有「重新校准投影」和「导出当前悬停对象数据」两个按钮，排查问题时很好用。

## 工作原理

1. `ctx.entities.list({ kinds: ['plant', 'zombie'], alive: true })` 拿到存活对象与 `snapshot()`（游戏坐标、行列、生命）。
2. 用 Cocos 相机（`cc.Camera.worldToScreen`）或画布视图变换把游戏坐标投影成屏幕坐标，自动挑选与画面最吻合的一种（用「行列应与屏幕方向相关」做自检）。
3. 与鼠标位置比对取最近对象（带滞回）；命中后**锁定**该对象，直到松开触发键。
4. 图鉴内容优先用游戏内数据域（`ctx.plants` / `ctx.zombies` 的 `getAlmanac` / `getProps`），取不到时回退到包内 `data/almanac.json`（由游戏 0.15.0 数据导出，233 种植物 / 388 种僵尸，含中英双语字段）。
5. 语言：`ctx.localization.getCurrentLanguage()` → 主语言；文案表 `zh` / `en`，数据字段按 `{zh, en}` 取词，缺失回退中文。

## 常见问题

- **按住 Shift 没反应**：确认「设置 → 实验性 → JS Modding」已开启，且模组已勾选并「应用」。
- **卡片位置偏了**：设置里换一种「坐标投影方式」，或用偏移量微调；调试信息里有候选得分。
- **想用英文**：游戏语言切到 English 即可；或把「图鉴语言」设为 English。
- **卡片显示「该对象没有图鉴条目」**：说明该对象不是标准植物/僵尸（如子弹、护甲），或 codename 未收录；可用「导出当前悬停对象数据」反馈。
